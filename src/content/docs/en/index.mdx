## What SentryAssets does

<CardGrid>
	<Card title="Inventory with provenance" icon="list-format">
		Assets with categories, locations down to the room, owners, lifecycle and
		relations. Every value shows where it came from. More under
		[Features](/en/reference/funktionen/).
	</Card>
	<Card title="Automatic discovery" icon="laptop">
		Agents for Linux and Windows, read-only and outbound only, a collector for network
		scans with SNMPv3 and LLDP, and Active Directory sync. Start with
		[Agents](/en/guides/agents/).
	</Card>
	<Card title="BSI IT-Grundschutz" icon="approve-check">
		Grundschutz++ and Edition 2023 with a guided process from the information domain to
		the Grundschutz check, every requirement explained in plain words. See
		[IT-Grundschutz](/en/guides/grundschutz/).
	</Card>
	<Card title="Security built in" icon="seti:lock">
		local accounts with mandatory TOTP, optional OIDC, an audit log with a hash chain, tenant isolation
		with row-level security, mTLS with TLS 1.3 for agents. More under
		[Security](/en/reference/sicherheit/).
	</Card>
	<Card title="Self-hosted" icon="setting">
		A hardened Docker Compose stack on your Linux server. The installation sends no
		usage data to the vendor. See [Installation](/en/guides/installation/).
	</Card>
	<Card title="Pro and Enterprise" icon="star">
		Protection inheritance, automatic modelling, connectors, check rules, workflows and
		more, to try for 30 days without a key. See
		[Licence and editions](/en/guides/lizenz/).
	</Card>
</CardGrid>

## Getting started

- [Installation](/en/guides/installation/) – start the stack with Docker Compose
- [Setup](/en/guides/einrichtung/) – setup wizard, local accounts, optional OIDC
- [Agents](/en/guides/agents/) – discover devices on Linux and Windows
- [IT-Grundschutz](/en/guides/grundschutz/) – the BSI Standard 200-2 way in the system
- [Backup and migration](/en/guides/sicherung/) – back up and restore the installation
- [Configuration](/en/reference/konfiguration/) – every setting of `.env`
