## Planned

- **Agent for macOS** as a launchd service, with the key in the system keychain.
- **Keys in the TPM or CNG** on Windows, not exportable.
- **A signed installer (MSI)** and Authenticode signatures for Windows.
- **Published, signed container images** instead of a build by the operator.
- **This documentation as knowledge base** of the help assistant.
- **PROXY protocol** for a load balancer in front of several hosts.
- **Backup and archive in S3-compatible storage** (Pro and Enterprise): off-site backups, immutable with Object Lock on request, encrypted before upload; later a long-term archive of closed records for retention periods.

## Known limitations

- The Windows agent is not yet Authenticode-signed; SmartScreen or virus scanners may report it.
- OIDC and the directory sync are checked against test servers, not yet against every combination of identity provider and Active Directory.
- Checking the audit chain reads the whole log; from about 25 million entries it exceeds a job's time limit.
- GPU load on Linux is available for the amdgpu driver only.
- Running across several hosts is described but not tested in every environment.

The changes of each version are in the changelog (`CHANGELOG.md`) in the repository.
